# MauiAppMeuCombustivel

Um programa de exemplo para demonstrar o uso do .NET MAUI (Multi-platform App UI)
para criar aplicativos móveis e de desktop com uma única base de código.
Este aplicativo específico é voltado para calcular o consumo de combustível de veículos.
E determinar qual está compensando mais no momento.

Aula do professor Tiago A. Silva - https://www.youtube.com/watch?v=nqmRx3WUqrY&t=242s
